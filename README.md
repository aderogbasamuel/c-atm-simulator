# ATM Simulation in C

A **console-based ATM simulation** written in C.  
This program demonstrates fundamental C programming concepts such as loops, functions, conditionals, and string handling.

## Features

- User login with **limited attempts**  
- Balance checking  
- Deposit money  
- Withdraw money (with overdraft check)  
- Press Enter to continue after each transaction for smooth user experience  

## How to Run

1. Clone or download this repository
2. Compile the program using `clang` or `gcc`:

```bash
clang atm.c -o atm
# or
gcc atm.c -o atm
